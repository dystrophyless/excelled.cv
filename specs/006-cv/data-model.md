# Data model: Student CV

## `student_cvs`

| Column | Type | Rules |
|---|---|---|
| `id` | uuid | primary key, generated by the application; changes on replacement |
| `profile_id` | integer | unique, not null, FK `student_profiles.id` `ON DELETE CASCADE` |
| `file_name` | varchar(150) | not null, cleaned (research R7) |
| `format` | enum `cv_format` (`pdf`, `docx`) | not null, from content |
| `size_bytes` | integer | not null, check 1..5242880 |
| `content` | bytea | not null, deferred; check `octet_length(content) = size_bytes` |
| `uploaded_at` | timestamptz | not null, set on upload and on replacement |

New table and type only, created by the existing `create_tables` script; existing tables do not change. No history is kept.

## Transitions

```text
none --upload--> uploaded --replace--> uploaded (new id, old content gone)
                 uploaded --remove---> none
```
